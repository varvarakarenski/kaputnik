TAKE PICTURE:
rpicam-still -t <shutter speed in ms> -o <name>.jpg

BASICS:
mkdir = make directory (folder)
ls = list contents
pwd = print working directory (where am i?)
cd = change directory
.. = current location
mv = move file
rm = delete file

COPY FILES TO LAPTOP/USB MANUALLY:
cp source-directory/<file-to-copy.whatever> destination-directory/.
To copy a directry, print -r after cp.
cp -r source-directory/<file-to-copy.whatever> destination-directory/.
